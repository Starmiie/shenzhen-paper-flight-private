# 先抵达 · 深圳纸飞机旅行

给每一个想去的人，一次先抵达。

这是可以实际飞行、收藏地点、拍照的 Babylon.js 网页游戏。本地审阅版本复用 linranff/GTA_SZ 的城市几何与景观，不是设计稿或替代方块城市；尚未公开发布。

## 海湾慢行样段 · 2026-09-16

本轮为人才公园—春笋—腾讯滨海大厦的第一版视觉与交互样段：暖金双翼拖尾、较柔和的黄昏光线、三处可点选的空中标签与路线入口、地标事实卡和资料来源。点击地标/路线打开介绍时暂停位移和时间，关闭后恢复之前的悬停/飞行状态；选中的建筑以淡金色叠色突出显示，公园以位置标签与地图点标示。

远景窗格改为更早过滤到平均色，玻璃粗糙度与纹理过滤提高；春笋肋条发光减弱，抗锯齿使用 2× MSAA + FXAA（取决于设备支持），相机近裁面调为 2 游戏米。立面瓦片提前到 1250 游戏米加载，进入 800 / 离开 950 游戏米的滞回避免边界来回闪断。仍使用原始建筑几何，不表示全城已重新建模或摩尔纹已完全消失。细密几何、夜景亮窗和特殊角度仍需后续路线测试。

事实卡目前覆盖以上三处，其余地点仍保留旅行随笔。参考桌面美术图的色彩和流光方向，未复制参考图或游戏素材到项目。资料链接点击后才访问外部网站。

## 打开体验

当前本机入口：<http://127.0.0.1:4173/>。服务关闭后可双击本目录的 `start.command`，或执行：

```sh
cd "/Users/tjh/Documents/Codex/2026-09-13/shenzhen-paper-flight/outputs/paper-shenzhen"
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

浏览器访问 `http://127.0.0.1:4173/`。按 Ctrl+C 停止服务。只绑定本机，不暴露局域网或公网。需要 Python 3；游戏本身不需要账号、API 密钥或在线服务。打开真实地图链接才会访问 OpenStreetMap。

**可运行 HTML：`dist/index.html`。必须通过 HTTP 服务打开，不能直接双击 file:// 文件。** 同目录的 `assets/`、`city/`、`licenses/` 和署名文件需要一起保留。已构建内容无需安装 Node.js。

## 操作

- 纸飞机持续缓慢前进；W/S 或 ↑/↓ 抬升、下降，A/D 或 ←/→ 转向；拖动场景也能转向。松开后逐渐平飞。
- Shift 乘风加速；空格悬停/继续。高空可俯瞰，低处可绕飞；接近模型时尝试轻柔避让，没有坠毁、战斗或惩罚。
- 时间入口可选清晨、午后、黄昏、深夜；虚拟 1 分钟约为现实 12 秒，周期内太阳高度缓慢变化。四种环境之间采用预设切换，不是连续天文或气象模拟。
- P 进入/离开拍照；时间和飞机停下，拖动环绕取景，滚轮变焦，也可以调整镜头距离和视野。H 隐藏/显示界面，Esc 返回。相机包含基础外部障碍裁剪，极窄楼缝处可能需要重新取景。
- “保存照片”下载 JPEG，附最近地点（或“沿途风景”）与游戏时间，同时写入本浏览器 IndexedDB。照片地点表示拍摄位置附近地标，不是图像识别结果。
- “感兴趣”“想去”为同一地点的两种互斥状态，再次点击可取消。我的旅程提供已标记/沿途地点/照片三个视图；地图可点选地点，方向指引只显示目标方位，不传送飞机。
- 照片可重新下载、在地图回看拍摄位置或删除。地点标记写入 localStorage。不同浏览器、不同端口的记录互不共享；无云同步或导出备份，清除网站数据会丢失记录。存储受限/已满时会提示；照片仍会尝试直接下载。
- 触控设备有方向、悬停、乘风按钮，但完整城市对移动设备负担较重；主要验证平台为本机 Codex 浏览器桌面视口。

上游：<https://github.com/linranff/GTA_SZ>

固定版本：`d61d243bffcc2f24a34f0036cfb844d3abc81992`。仓库事实与来源副本见 `provenance/`。

保留原基础城市、地标替换增量、全部近景立面瓦片、道路、地形、海岸、对岸远景、山体、植被和草地、招牌、座椅、公共照明与 HDR 环境。原清单约有 16,076 个建筑条目、12,202 个道路片段；它们不是独立楼栋或现实道路数量。近景立面与植被沿用按位置加载/显示的机制，全部原资源均可随飞行访问。

未扩展深圳全行政区。原场景范围来自上游清单：经度约 113.915–114.135，纬度约 22.497–22.575；现有城市、远岸与艺术处理不应解释为精确测绘。

13 个可标记地点来自原始城市清单与地标增量；不为普通背景建筑编造介绍。少量原创短文为旅行随笔，不是事实介绍。未使用《寄梦远方》的图像、模型、音乐或文字素材。

游戏坐标原点是 WGS84 `[114.025,22.536]`，计算关系：

```
游戏 X = (经度 - 114.025) × 102850 × 0.60
游戏 Z = (纬度 - 22.536) × 111320 × 0.60
```

水平、垂直均按 0.60 缩放，另有地形和道路艺术处理。页面标明“游戏高度/游戏距离”和“压缩游戏地图”。真实地图链接直接使用原项目地点清单的 WGS84 经纬度，不把游戏 X/Z 当经纬度，也不推算未提供的位置。

## 开发与验证

源码入口 `src/paper-main.ts`，三维场景与飞行 `src/paper-world.ts`，样式 `src/paper.css`。开发页面 `index.html`，构建产物在 `dist/`。

```sh
npm ci
npm test
npm run build
npm run dev
```

建议 Node.js 22.14 或更新兼容版本。本地 `node_modules` 链接只是工作区缓存，可删除后执行 `npm ci`。版本由 package-lock.json 固定。源码和已构建景观各保留一份，便于直接体验及后续修改；单份静态站点约 282 MB。

构建会提示 Babylon 主包体积较大（约 6.5 MB，gzip 约 1.45 MB）；这是需要继续优化的加载成本，不是构建失败。首载还需解析城市 GLB 与 HDR，低性能 GPU 会明显卡顿。首次启动耐心等待按钮变为“把自己交给风”。没有针对所有浏览器和手机验证，不承诺统一帧率。

验证细节与已知限制见 `VERIFICATION.md`；景观文件哈希见 `provenance/asset-inventory.json`。
